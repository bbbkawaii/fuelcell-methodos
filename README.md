# FuelCell MethodOS

面向「浦发·IGNITE 未来能源黑客松」T02 的最小可演示原型：把燃料电池测试时序数据转成**可配置、可复算、可审核**的工程结论。

> 这不是“聊天式 Agent”。核心链路是 `CSV → Method → 稳定区间 → Finding → 工程师复核 → 报告`。

## 直接体验

无需安装依赖。直接用浏览器打开 [index.html](index.html)，或在仓库目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173`，点击「加载 Mock 数据」。也可以点击「下载 Mock CSV」，再通过“导入 CSV”走一遍真实的本地导入链路。

内置 Mock 数据会得到：

- 一个 120 秒的正式统计窗口；
- `Cell 07` 相对群体偏低的可复核 Finding；
- 两段氢气压力越界的可定位证据；
- 可切换的工程师复核状态，以及可下载的 HTML 报告。

## 已实现能力

| 环节 | Demo 行为 |
| --- | --- |
| 数据导入 | 本地读取 CSV，不上传原始数据；会校验必需信号字段。 |
| Method | 可编辑目标电流、压力/温度容差、最短稳定时长、统计窗口和单体离群阈值。 |
| 规则判定 | 连续平台、连续稳定区间、120 秒正式统计 / 短窗口预警、数据完整度检查。 |
| Finding | 单体电压相对群体中位数的偏差、平台内供氢压力越界都带时间范围与原始字段证据。 |
| 人工闭环 | 每条待处理 Finding 可标记“已复核”，报告同步记录审核状态。 |
| 交付 | 导出不含原始时序数据的 HTML 报告，保留 Method 版本、参数、窗口、证据标识与结论。 |

## CSV 约定

最小必需字段是电流、氢气压力、空气压力和冷却液温度；时间列缺失时按行序号处理。以下表头可直接导入：

```csv
timestamp,current,h2_pressure,air_pressure,coolant_temp,stack_voltage,cell_01,cell_02
0,100.0,200.1,179.8,65.0,50.92,0.675,0.677
1,100.1,200.0,180.2,65.1,50.90,0.674,0.676
```

也会尝试识别常见中文表头，例如「堆电流」「氢气压力」「空气压力」「冷却液温度」「单体电压」。带有 `cell`、`单体`、`电池片` 或 `单节` 的字段会作为单体电压参与一致性检查。

## 项目边界

- 仓库中的 Mock 数据由前端合成，并可在页面一键下载为 CSV；不包含比赛企业的原始测试资料。
- 当前版本是静态前端 MVP，所有分析在浏览器中运行，便于线下演示和保护测试数据。
- 后续可接入 T02-03 的真实字段映射、批量工况拆分、Excel 多 Sheet 报告和企业权限体系。
